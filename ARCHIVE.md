# Archive restoration

Prepared 2026-11-03 from local files and connected Drive coursework.

JavaScript frontend, TypeScript/Node backend, PostgreSQL and Docker.

## Original state

Archived coursework. Backlog entries are not proof that each feature is implemented. The original async service and lookup issues are retained.

Incorrect code, TODOs and unfinished exercises are intentionally retained. No claims of successful execution or correctness were added. Preparation changes are limited to organization, privacy/credential cleanup, text exports and documentation; notebook outputs and identifying metadata were cleared.

## Dates

Original file modification timestamps were recorded before copying. The accompanying commit plan uses those timestamps for GIT_AUTHOR_DATE and GIT_COMMITTER_DATE, to whole-second precision in UTC. Original millisecond values remain in the manifest. Timestamp reconstruction is an archival import, not a recovered sequence of intermediate edits. Supplied libraries/scaffolding can have older timestamps than the student's work.

Documentation written during restoration is dated 2026-11-03. Existing Git history must be preserved for projects under existing-repository-updates.

## Setup

From the project root, use the original Docker Compose configuration. The backend README also documents its development setup.
